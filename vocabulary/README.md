# Vocabulary lists

Lists of terms for Hush’s Vocabulary, so transcripts spell a subject’s words the way they’re written: ml5.js, not “ML five JS”; analogRead, not “analog read”.

- `machine-learning.md`
- `physical-computing.md`
- `creative-coding.md`

To use one, open Settings › Vocabulary in Hush, click Import… and choose the file (or drop it on the list). Turn on the lists for what you’re recording. Long lists are fine: Hush picks the terms each stretch of speech seems to need.

Each list is Markdown: headings group the terms, and each term is on its own line, written exactly as it should appear, capitals included. Hush also reads plain text (one term per line) and comma-separated lists.
